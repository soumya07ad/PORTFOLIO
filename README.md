## 🌌 Overview

Modern interactive portfolio featuring:
- **WebGL2 Relativistic Black Hole (`EtchedAccretion`)**: Procedural relativistic accretion disk with interactive mouse parallax drift and singularity feeding physics.
- **3D GitHub Contribution Skyline (`ContributionSkyline`)**: GitHub-style activity heat map with smooth isometric 3D folding and orbital drag controls.
- **AI Architecture Matrix**: Interactive HUD showcasing Multi-Agent pipelines, SSE streaming gateways, Model Context Protocol (MCP) bridges, and on-device ML telemetry.
- **Selected Engineering Repositories**: Real production repositories (`ble-ring-app`, `ClearScanOCR`, `QuizForge`, `PocketLedger`, `AM-Portfolio`).
- **Sticky Glassmorphic Navigation**: Global header anchored on scroll for seamless section navigation.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Vanilla Glassmorphism
- **Shaders & 3D**: WebGL2 Fragment Shaders + Canvas 2D/3D Projection
- **Icons**: Lucide React
- **Typography**: Space Grotesk, Outfit, Plus Jakarta Sans, JetBrains Mono

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/soumya07ad/PORTFOLIO.git

# Navigate into directory
cd PORTFOLIO

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
npm run preview
```
